# Universal Remote 0.3 — Android

Приложение обнаруживает устройства пользователя рядом и в текущей локальной сети и показывает только те функции управления, для которых есть реальный поддерживаемый протокол.

## Что добавлено в 0.3

- красивые векторные иконки для ТВ, компьютеров, колонок, света, проекторов, телефонов и другой техники;
- BLE без искусственного ограничения расстояния в 99.9 м; для слабого сигнала показывается `100+ м` / «далеко»;
- поиск Bluetooth LE, mDNS/Bonjour, SSDP/UPnP и активных хостов текущей LAN;
- дополнительные mDNS-типы: Google Cast, AirPlay/RAOP, Android TV Remote, Matter, HomeKit, IPP, Spotify Connect;
- поиск/фильтры и отдельные настройки источников обнаружения;
- RecyclerView + DiffUtil + пакетное обновление интерфейса для плавной работы при 100+ найденных устройствах;
- удаление дубля «голого» LAN-IP, если этот же хост уже найден через более информативный протокол;
- реальное стандартное управление UPnP MediaRenderer: громкость, mute, Play/Pause/Stop;
- реальное PJLink-управление питанием, громкостью и mute совместимых проекторов; поддерживается PJLink 2.10 SHA-256 и legacy challenge-response;
- галочка `✓` означает, что управление устройством уже успешно выполнялось в текущей сессии приложения.

## Безопасность паролей

Приложение не подбирает, не обходит и не «взламывает» пароль. В PJLink введённый пароль используется только для текущей команды, не сохраняется на диск, а временный массив символов очищается после команды. Если протокол устройства использует pairing token/сертификат, для него нужен отдельный штатный адаптер.

Нельзя одновременно «не хранить пароль вообще» и затем автоматически снова пройти парольную авторизацию без ввода: для повторного входа устройство должно выдать безопасный токен либо пароль нужно ввести повторно.

## Физические ограничения Android

Обычный смартфон не является широкополосным SDR-приёмником и не может перечислить все устройства, которые «что-то излучают» на произвольных радиочастотах (433 МГц, Zigbee без радио, произвольный RF, ИК и т. п.). BLE и Wi‑Fi обнаруживаются штатными радиомодулями телефона. Для других диапазонов нужен соответствующий внешний адаптер/шлюз.

Оценка расстояния BLE по RSSI приблизительная и может сильно меняться из-за стен, корпуса и ориентации устройства. Значение свыше 100 м не означает точное физическое расстояние.

## Сборка

Проект использует AndroidX и уже содержит `android.useAndroidX=true`. GitHub Actions workflow собирает debug APK командой:

`gradle :app:assembleDebug`

APK после CI: `app/build/outputs/apk/debug/app-debug.apk`.
