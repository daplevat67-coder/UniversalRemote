# Как получить APK

## Через Android Studio

1. Распакуйте архив и откройте папку `UniversalRemote`.
2. Дождитесь загрузки компонентов проекта.
3. Выберите **Build → Build APK(s)**.
4. Файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Автоматически через GitHub

1. Создайте пустой репозиторий и загрузите туда содержимое папки проекта.
2. Откройте вкладку **Actions** → **Build Android APK** → **Run workflow**.
3. После сборки скачайте архив **UniversalRemote-debug-apk** внизу страницы запуска.

Android может предупредить об установке из неизвестного источника — это нормально для тестовой сборки вне Google Play.
